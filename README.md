<summary><strong>Doc AI Agent · From a question to its source</strong></summary>

Ask a question about technical documentation in a Streamlit interface. The agent searches the documentation and returns an answer with references, so the reader can check the original text.

I used minsearch for keyword retrieval and Pydantic AI with a Groq-hosted model to compose the answer.
